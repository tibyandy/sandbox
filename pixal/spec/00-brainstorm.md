# Locxv: Local Pxv
## Left Panel
Takes around 15% of screen width. Can be resized.

### Navigation
Takes the top part of the left panel. Contains these links
1. [H] Home
2. [S] Sessions
3. [F] Favorites
4. [A] Artists
5. [W] Works
6. [T] Tags
7. [D] Discovery

When one of the options is clicked, the navigation is collapsed to take only 1 line displaying the active option.
When hovered, expands to show all options.
When mouse moves out from the left panel, navigation collapses after 1s.

### Details Panel
1. Thumbnail (vertically resizable)
2. Work Referrer (with thumb)
3. Action Buttons
   1. Favorite
   2. View Similar
   3. View From Artist
   4. Dismiss (mark as viewed)
4. Type description: Illust, Collection, Ugoira, Manga, Novel
5. Work Title
6. Work Artist
7. Work Tags, grouped by TagCategories
8. (For collections) First thumbnails (fill up to screen height, then show +X)
   1. On click, open this collection as a "folder"
